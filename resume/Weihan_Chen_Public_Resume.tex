\section*{Projects}
\href{https://gyoichii.github.io/projects/isomorph/}{\textbf{Isomorph}} \enspace|\enspace Recommendations across books, films and music \hfill Nov 2026 -- Present
\begin{itemize}
\item Built a recommender that uses a reader's journal to infer what they liked about a work. It scores new candidates against competing explanations of the reader's taste, then uses integer programming to select a mix of books, films and music.
\item Moved recommendation generation off the request path. A background worker prepares cards and discards them when the reader's profile changes. With ten cards ready, the first appeared in \textbf{0.39 s}, compared with 172 s on demand.
\item Shortened the wait for new readers by turning off model reasoning for profiles with fewer than five rated works. Across five runs per setting, median time to the first three recommendations fell from \textbf{146 to 69 s}.
\end{itemize}

\par\addvspace{6pt}
\textbf{Friday Night} \enspace|\enspace \href{https://fridaynight.love}{fridaynight.love} \hfill Jun 2026 -- Present
\begin{itemize}
\item Independently built and launched a web app where groups vote on films, watch together, and meet in shared Three.js rooms. It reached \textbf{126 registered users}.
\item Serialized competing playback commands with a PostgreSQL row lock per room. Per-client sequence numbers let the server discard late playback reports before they replace a newer checkpoint.
\item Load-tested simultaneous pauses across \textbf{100 rooms} on a single machine. Every simulated viewer received the correct update, with \textbf{40.6 ms at p95} from the host's HTTP request to the viewer parsing the update.
\item Moved accounts and shared watchlists from SQLite to PostgreSQL in one transaction, comparing row counts and normalized content hashes for every table before committing.
\item Used Redis to prevent duplicate Douban watchlist reads. In a local test, 500 concurrent requests from one user triggered one read while another user's preview completed.
\end{itemize}

\par\addvspace{6pt}

\begin{itemize}
\item Built fast-paced melee combat with Unreal's Gameplay Ability System (GAS) and a C++ state machine. Players queue strikes mid-swing and break enemy combos with timed parries.
\item Built C++ procedural tools that generate an urban-village-inspired district from a saved plan. A designer can regenerate one building's interior while the surrounding parcels and entrances stay in place.

\end{itemize}
