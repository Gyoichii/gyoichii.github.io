\section*{Projects}
\href{https://fridaynight.love}{\textbf{Friday Night}} \enspace|\enspace Synchronized watch parties \hfill Jun 2026 -- Present
\begin{itemize}
\item Independently built and launched a web app where groups vote on films, watch together, and meet in shared Three.js rooms. It had \textbf{122 registered users} as of Nov 10, 2026.
\item Kept viewers on the same timeline while letting each choose a playback quality. A Java/Spring Boot service orders playback commands with PostgreSQL row locks and broadcasts updates over WebSockets.
\item Load-tested 500 WebSocket connections across 100 rooms on loopback. When all hosts paused at once, all 400 simulated viewers received their room's update. Latency from HTTP request start to client-side parsing was \textbf{40.6 ms at p95}.
\item Migrated accounts and shared movie lists across 17 tables in one PostgreSQL transaction. The importer compared row counts and SHA-256 hashes of normalized records before committing.
\end{itemize}

\par\addvspace{6pt}
\href{https://gyoichii.github.io/projects/rivering/}{\textbf{Project Rivering}} \enspace|\enspace Independent Unreal Engine 5 action game \hfill Apr 2026 -- Present
\begin{itemize}
\item Built C++ procedural tools that regenerate individual buildings from a saved district plan. Checked entrances against the player collision capsule and verified all 34 street access routes after an in-place rebuild.
\item Profiled a 23-building district with 133,592 instances. Skipping redundant decal and cutaway updates and simplifying curtain meshes cut mean frame time \textbf{33\%} (20.86 to 14.04 ms) in two 300-frame Play-in-Editor captures at $1792\times746$.
\item Implemented server-side melee hit detection with Unreal's Gameplay Ability System. Sweeps between weapon poses register each target once per attack, even when contact spans multiple frames.
\end{itemize}
