# Weihan Chen — portfolio

Live: **https://gyoichii.github.io/**

Static Next.js / React / TypeScript portfolio with three engineering case studies, mixed-media galleries, and a self-hosted font. No database, login, tracking script or runtime server.

## Run

Node.js 22.13+; CI uses Node 22 LTS.

```sh
npm ci
npm run dev
```

Development: http://localhost:3000. Restart after adding media to regenerate the manifest.

```sh
npm run verify
npm run build
npm start
```

`verify` runs TypeScript, ESLint and media-discovery regression tests. `build` regenerates the media manifest, checks types and exports to `out/`. Production preview: http://127.0.0.1:4173.

## Edit

- `src/data/projects.ts`: case-study copy, chapters and technical notes.
- `src/data/media-slots.json`: media names, captions and display fit.
- `public/media/<project>/`: drop-in images/films; follow [MORNING_MEDIA_CHECKLIST.md](MORNING_MEDIA_CHECKLIST.md).
- `src/data/media.generated.json`: generated by dev/build/media:sync; never edit manually.
- `app/globals.css`: responsive layout and reduced-motion treatment.
- `public/resume.pdf`: public resume copy with phone number removed.

The viewer accepts MP4, WebM, GIF, WebP, JPG/JPEG and PNG. Video takes precedence over stills with the same basename; MP4 precedes WebM. Matching stills or `-poster` images supply video posters. Previews are muted, viewport-gated, paused offscreen/when the page is hidden, and disabled for reduced-motion/data-saver preferences. Pause controls stop previews. Expanded videos use native controls. Galleries support Escape, arrow keys, buttons, swipe and focus restoration. Missing media has designed placeholders.

The long occlusion GIF uses `preview: "poster"` in the media manifest: its full animation downloads only when explicitly opened. The shorter building-dimensions GIF animates inline and supports pause/reduced-motion posters.

## Publish

The `main` branch deploys via `.github/workflows/pages.yml`: clean install → verify → build → GitHub Pages. Review and commit only intended changes, push main, then check Actions. No custom domain or DNS changes are needed.

Another host can serve the entire `out/` directory at its domain root, preserving directory-index routes. Update `metadataBase` in `app/layout.tsx` and canonical metadata if moving the public URL. `vercel.json` also supports static export.

Source projects remained read-only. This repository contains portfolio code and presentation assets, not production repositories, credentials, databases or account data. Implementation notes distinguish source evidence from runtime acceptance.

## Validation

The production export was browser-checked at 1440, 1024 and 390 px on all four routes, covering overflow, image loading, console errors, direct refresh, navigation and lightbox keyboard/focus behavior. Temporary MP4/WebM/GIF fixtures verify playback and reduced-motion behavior and are not shipped. Website validation does not imply new runtime testing of the featured projects.
